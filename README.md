# 👻 Ghost Radar

Ghost Radar é um aplicativo mobile desenvolvido com React Native e Expo que simula um detector paranormal utilizando criaturas da API de Dungeons & Dragons.

O aplicativo detecta “entidades” aleatórias, exibindo:
- nome
- tipo
- nível de ameaça

Tudo isso em uma interface inspirada em radares paranormais.

Este projeto foi criado como prática de:
- React Native
- consumo de APIs
- desenvolvimento mobile
- integração futura com hardware
- evolução para fullstack

# ⚙️ Como Instalar

## 1. Clonar o repositório

```bash
git clone https://github.com/C-26hub/Ghost-Radar.git
```

---

## 2. Entrar na pasta

```bash
cd Ghost-Radar
```

---

## 3. Instalar dependências

```bash
npm install
```

---

## 4. Instalar Axios

```bash
npm install axios
```

---

## 5. Rodar o projeto

```bash
npx expo start
```

---

# 📲 Como Executar no Celular

1. Instale o aplicativo Expo Go
2. Rode o projeto com Expo
3. Escaneie o QR Code
4. Abra o aplicativo no celular
